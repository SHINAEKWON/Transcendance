********************************************************************************
package.json
- https://www.geeksforgeeks.org/node-js-package-json/
- https://docs.npmjs.com/cli/v11/configuring-npm/package-json

The file package.json is create when initializing a npm project with 'npm init'.
It contains dependencies, scripts, metadata for the project.
Dependencies / devDependencies are added when running e.g. 'npm install --save-dev [module]'.

Some data stored :
* name
* version
* description
* main: the entry point of the application
* scripts: the scripts needed to be included in the app
* keywords
* author
* license
* devDependencies: dependencies that are only used in the deveopment part, not 
  rolled out in production

********************************************************************************
package-lock.json
- https://stackoverflow.com/questions/44297803/what-is-the-role-of-the-package-lock-json

The command 'npm install --save-dev [module]' creates the file package-lock.json.
The command also creates the folder node_modules.
The file is an exact, versioned dependency tree (see stackoverflow above)

********************************************************************************
node_modules
- https://stackoverflow.com/questions/63294260/what-is-the-purpose-of-the-node-modules-folder

The command 'npm install --save-dev [module]' creates the folder node_modules.
The folder contains all the modules the project depends on.


********************************************************************************
tsconfig.json
- https://stackoverflow.com/questions/50605219/difference-between-npx-and-npm

The file is created with the command 'npx tsc [options]'.
The file defines the typescript options.
* rootDir: typescript looks here for the code, it includes the typescript files
* outDir: typescript puts the compiled code here
* esModuleInterop: if we use commonjs as module system (recommended for 
  Node.js), this must be true
* resolveJsonModule: if we use json in the project, this allows typescript to 
  use it
* adds ambient types to our project to use libraries, DOM api, etc.
* module commonjs: standard module for Node.js
* noImplicitAny: don't allow a type to be implicitly be declared as 'any'
